# slcm feedback automation

because apparently we need to fill out 67 feedback forms before accessing anything else on slcm.

### what it does
- selects `yes` for unanswered radio questions
- sets dropdowns to `yes` wherever available
- doesn't submit anything. you're on your own for that.

### how to use
1. open slcm and navigate to a feedback form
2. open devtools → console:
   - **mac:** `cmd + option + j`
   - **windows/linux:** `ctrl + shift + j`
3. paste the contents of `slcm-feedback.js`
4. press enter. enjoy your 3 seconds of freedom.
